# Pull to read, push to watch — interactive documentary UX prototype (sample)

Live demo: https://hadischolar6.github.io/pull-to-read-documentary/

A clickable mobile-first prototype for a UX challenge: how can a visitor watch a documentary about a city and read more
about a historical event or empire whenever something interests them, then carry on watching?

- Watch: the film plays at the top; an "On screen now" strip names the moment being narrated, with the chapter transcript under it.
- Pull to read: scrolling up shrinks the film into a strip, pauses it, and opens the card for that exact moment
  (Key evidence, Places, People, Primary sources).
- Push to watch: scrolling back to the top (or tapping Resume) continues the film from the start of the sentence you left.
- Save without stopping: tap the star to keep a moment; at the end of each chapter a short "Story break" replays only
  the moments you starred.

Best viewed on a phone, or in a desktop browser (it shows a phone-sized frame; use the mouse wheel to pull and push).
